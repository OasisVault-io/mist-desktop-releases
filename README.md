# Mist Desktop

Installers for Mist Desktop, a Mist-branded fork of [Hermes Agent](https://github.com/NousResearch/hermes-agent).

Download: https://getmist.ai/download

This repository distributes installers only. It contains no account credentials or private service configuration. Release notes identify the source revision, supported platform, checksum, and signing/notarization status for each build.
